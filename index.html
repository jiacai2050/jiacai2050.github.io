About Me

I am a Senior Software Architect at Xiaomi Technology based in Hangzhou, currently leading incremental Rust adoption across HyperOS — from the application layer to the core service framework layer — eliminating memory safety risks while elevating developer productivity through modern compiler checks.

Previously, I worked at Ant Group as an Infrastructure Platform Engineer, designing and implementing CeresDB, the distributed time-series database powering internet-scale metrics storage.

My deep interests center on systems programming, software architecture, OS & runtime internals, compilers, and database engines. Long-time Emacs hacker and active builder in Rust, Zig, Go, and Clojure.
